# RPX Generic AI Templates
#
# Idea-gated division templates for generic minors using the RPX focus tree.
# Each role has multiple variants gated on ideas (focus completions) and tech.
# regimental_support attaches per column with 3+ line battalions.
# Fallback templates exist when no relevant idea is taken.
